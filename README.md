# Library App

## 1. Problem Statement
A Library App is required to manage books, users, borrowing, and returning of books efficiently. The system should allow users to search for books, borrow and return books, while librarians can manage the book catalogue.
## 2. Scope
The Library App will provide:
- User login and authentication.
- Searching and viewing available books.
- Borrowing books.
- Returning borrowed books.
- Adding, updating, and removing books.
- Maintaining basic book and borrowing information.

## 3. Stakeholders
| Stakeholder                | Role                                 |
| -------------------------- | ------------------------------------ |
| Library Users/Students     | Search, borrow, and return books     |
| Librarian                  | Manage books and borrowing records   |
|   Administrator            | Manage users and system access       |
| College Management         | Monitor library operations           |
| Development Team           | Develop and maintain the application |

## 4. Functional Requirements
FR1 – User Login
The system shall allow registered users to log in.

FR2 – Search Books
The system shall allow users to search for books by title, author, or category.

FR3 – View Books
The system shall display book details and availability.

FR4 – Borrow Books
The system shall allow users to borrow available books.

FR5 – Return Books
The system shall allow users to return borrowed books.

## 5. Non-Functional Requirements
NFR1 – Usability
The application should have a simple and user-friendly interface.

NFR2 – Performance
Search results should be displayed quickly.

NFR3 – Security
Only authorized users should access protected functions.

NFR4 – Reliability
The system should maintain accurate book and borrowing records.

NFR5 – Maintainability
The application should be easy to update and maintain.
